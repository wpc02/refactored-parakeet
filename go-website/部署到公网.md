# 把围棋入门网站部署到公网

## 方式一：最快（临时公网地址，适合测试）

1. 先启动网站：

   ```bat
   cd /d "C:\deepseek  harness\weiqi\go-website"
   C:\Python\python.exe app.py
   ```

2. 再打开另一个命令窗口，运行：

   ```bat
   cd /d "C:\deepseek  harness\weiqi\go-website"
   公网穿透-cloudflared.bat
   ```

3. 窗口里会出现一个网址，例如：

   ```text
   https://xxxx.trycloudflare.com
   ```

   把这个网址发给别人，就能访问你的网站。

> 说明：这种方式网址是临时的，程序关闭后会失效。

## 方式二：长期部署到云服务器

### 1. 准备一台 Linux 云服务器

安装 Python 3：

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip nginx
```

### 2. 上传项目

把 `go-website` 文件夹上传到服务器，例如：

```text
/root/go-website
```

### 3. 安装依赖

```bash
cd /root/go-website
python3 -m venv venv
source venv/bin/activate
pip install flask gunicorn
```

### 4. 使用 gunicorn 启动

```bash
gunicorn -w 2 -b 127.0.0.1:8080 app:app
```

### 5. 配置 Nginx

编辑 `/etc/nginx/sites-available/go-website`：

```nginx
server {
    listen 80;
    server_name 你的域名.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/go-website /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 6. 配置域名解析

把域名 A 记录指向服务器公网 IP。

### 7. HTTPS（可选）

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名.com
```

完成后即可通过：

```text
https://你的域名.com
```

访问网站。
